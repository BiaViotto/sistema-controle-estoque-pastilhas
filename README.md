# Sistema de Controle de Estoque de Pastilhas Industriais 

O projeto consiste no desenvolvimento de um sistema para controlar o estoque de pastilhas industriais da DDA Metalúrgica. A solução permitirá registrar entradas e saídas, acompanhar as quantidades disponíveis e emitir alertas quando o estoque estiver baixo. Dessa forma, o sistema ajudará a reduzir erros, evitar a falta de materiais e facilitar o controle e planejamento das compras.
