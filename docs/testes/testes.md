# Plano de Testes

## Cadastro de Pastilha

Entrada:
Cadastrar uma nova pastilha.

Resultado esperado:
Pastilha salva no sistema.


## Entrada de Estoque

Entrada:
Adicionar 50 unidades.

Resultado esperado:
Quantidade atualizada.


## Saída de Estoque

Entrada:
Retirar 10 unidades.

Resultado esperado:
Estoque reduzido.


## Estoque mínimo

Entrada:
Quantidade menor que o limite.

Resultado esperado:
Sistema gera alerta.


## Código de barras

Entrada:
Realizar leitura do código.

Resultado esperado:
Sistema encontra a pastilha correta.
