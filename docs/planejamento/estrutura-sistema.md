# Estrutura do Sistema

## Módulo de Usuários
Responsável pelo controle de acesso ao sistema.

Funções:
- Login
- Autenticação
- Controle de permissões


## Módulo de Pastilhas
Responsável pelo cadastro e consulta dos materiais.

Funções:
- Cadastrar pastilha
- Consultar pastilha
- Atualizar quantidade


## Módulo de Estoque
Responsável pelas movimentações.

Funções:
- Entrada de materiais
- Saída de materiais
- Atualização automática


## Módulo de Código de Barras
Responsável pela identificação das pastilhas.

Funções:
- Ler código
- Localizar produto
- Confirmar movimentação


## Módulo CSV
Responsável pelo armazenamento dos dados.

Funções:
- Ler arquivos CSV
- Atualizar informações
- Salvar alterações


## Módulo de Relatórios
Responsável pelas informações gerenciais.

Funções:
- Relatório de estoque
- Histórico de movimentações
- Consumo de materiais
